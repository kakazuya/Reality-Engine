# Shared rules for v4 build workers (31 Oct 2026)

- **Authority:** `tasks/arch_v4/QUERY_V4_DESIGN.md` (v4.2). Read only your sections: use grep for the headings, then ranged reads. Do not read the whole document.
- **Golden rule:** pilot stores only (60 ISINs, `reality_engine/data/pilot/pilot60/`, opened `mode=ro&immutable=1`). No full-scale build, no embedding, no paid models. Never read a DB from D:.
- **Point in time:** every row carries `known_at` from the filing record, never a crawl date. `period_end` is not a publication date. A value is usable only from its `known_at`.
- **Proxy rule:** a proxy is the last resort and needs a `search_log` plus Opus approval; `real_answered` and `proxy_answered` are reported separately. A typed NOT IN DATA is never an answer.
- **Grading:** never loosen a check to raise a score. If a check looks wrong, report it.
- **Outputs:** code in the files your work package names; generated DBs in your workspace `.tmp/`, named in your report, for the controller to install. Do not commit generated DBs or large JSONL.
- **Tools:** `mcp__code-intel__*` for Python navigation; read/grep/glob tools for files; `mcp__reality-data__sql` and `schema` for DB questions; independent read-only calls in one parallel batch; no sleep loops.
- **Report:** what was built, acceptance numbers against the design's targets, what failed, install steps for the controller, code-intel calls vs grep/read/pwsh, calls before first edit.
