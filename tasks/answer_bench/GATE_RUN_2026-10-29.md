## 5. Method / deviations

- The hand-60 rerun is the *current* code on the *current* stores, not the stored pilot answers: two rows (MB0010#L, MB0122#L) now carry the asked public-holding row the pilot answer lacked, and the gate still downgrades them because the answer mixes in rows outside the named month.
- The gate judges only the row fields the answer shows: a hidden numeric key ("high": 1710.0) is not evidence that the answer reported a high, and a fallback ask needs two key terms, not one generic word. Event/relation asks got their own aliases (control change, auditor resignation, chart pattern, NIM, loan growth, lag, credit cost, options).
- The strict grader recomputes the gate from the 8 recorded rows and the hop's rendered detail, never from the planner's flags. It disagrees with the planner's flags on 1,591 rows (2,817 hop flags): the record caps rows at 8 and detail at 600 characters, so a concept carried only by a later row is invisible to it. The grader's verdict is the one reported; the disagreement is counted, not resolved in the planner's favour.
- The bank was re-run end to end under the fixed gate (1,073 originals + 1,608 instances); the earlier partial run's files are kept in .tmp/ as *_v1.jsonl.
- Pilot stores were read immutable: REALITY_CHUNKS_V3=D:\RealityEngine\pilot\pilot60\chunks_v3_pilot.db, REALITY_PILOT_T1=\pilot\pilot60, REALITY_MACRO_PILOT_DB=\pilot\macro_all.db.
