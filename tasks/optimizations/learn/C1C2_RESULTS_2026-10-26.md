**Verdict:**
- **v2 wins every slice, decks included** (+11.5 pts R@1 on decks). v2 chunks are less than half the size of the old
  ones, so the win is not from bigger windows; each hit also costs less context.
- This **reverses round 3's deck result** (40 deck questions, .550 vs .625). The 200-question deck set outranks it.
  P2 loaded decks into `chunks_v2.db` with the old chunker. Re-chunking decks with v2 is a local, free step, so do it
  before any embed run.

  remain a structured-value layer (numbers to `facts()`), not a search corpus.
- Defect: the script's budget-recall columns read 0.0 (char length not passed to the scorer); FTS budget numbers from
  the worker stand. R@k/MRR are unaffected.
