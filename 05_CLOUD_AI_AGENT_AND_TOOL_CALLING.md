## 1. Agent Architecture & Role

The Cloud AI Agent acts as an **autonomous synthetic reasoning layer**. It takes the **Top 20 candidates** generated by the quantitative screener and performs iterative multi-step tool calls against the local SQLite and LanceDB databases.

The agent investigates:
1. *Is the price breakout confirmed by genuine institutional accumulation (delivery volume spike)?*
2. *Is the business accelerating its earnings or expanding margins according to the latest quarterly reports?*
3. *What specific catalysts (CAPEX, new orders, plant commissioning) were disclosed in the earnings concall?*
4. *Are technical chartists and Telegram forum threads identifying high-probability setups or warning of distribution?*

## 3. Agent System Prompt & Reasoning Directives

```text
You are the Chief Quantitative Equity Strategist & Market Reality Modeling Specialist for Indian Equities (NSE/BSE).

Your mission is NOT merely to generate routine daily tips, but to operate as a Bottom-Up Causal Market Reality Engine. You possess a distilled knowledge graph connecting Stocks <-> Value Chains <-> Geographies <-> Macro/Geopolitical/Military forces.

When evaluating candidate stocks or responding to market-wide selloffs and shocks:
1. Examine the Causal Plumbing: Identify the company's real-world business drivers, raw material dependencies, transit routes, and policy tailwinds using distilled parameters and concall search tools.
2. Stress-Test Crisis Situations: When the market panics or falls, determine whether a stock's underlying business is genuinely impaired or whether it is experiencing indiscriminate panic-dumping (collateral damage), creating an asymmetric risk-reward entry window.
3. Verify Institutional Flow: Examine delivery volume spikes (>2.0x 20-day SMA) and delivery percentage (>50%) to confirm whether smart money is quietly accumulating during the drop.
4. Cross-examine Fundamentals: Look for QoQ/YoY revenue acceleration, EBITDA margin resilience, and capex commercialization timelines.
5. Synthesize Actionable Asymmetric Theses: Provide clear Recommended Entry Range, Target Price, Stop Loss (anchored to structural support / swing lows), and Risk-to-Reward Ratio (minimum 1:2.5).

You must output your final decision in strict Pydantic JSON format matching the DailyAlphaReport schema.
```

## 4. Structured Output Pydantic Schema

```python
from pydantic import BaseModel, Field
from typing import List, Optional
from enum import Enum

class ConvictionLevel(str, Enum):
    HIGH_CONVICTION = "HIGH_CONVICTION"
    MODERATE = "MODERATE"
    SPECULATIVE = "SPECULATIVE"

class TradeSetup(BaseModel):
    current_market_price: float = Field(..., description="Latest EOD closing price")
    entry_range: str = Field(..., description="Recommended buying range, e.g., '₹2,450 - ₹2,480'")
    target_price: float = Field(..., description="Target price based on resistance/fibonacci extension")
    stop_loss: float = Field(..., description="Strict stop loss below key support level")
    risk_reward_ratio: float = Field(..., description="Target profit / Maximum risk ratio, e.g., 3.2")
    time_horizon_weeks: int = Field(..., description="Expected holding period in weeks, e.g., 4-12")

class ScripEvaluation(BaseModel):
    symbol: str = Field(..., description="NSE Ticker Symbol")
    company_name: str
    composite_rank: int = Field(..., ge=1, le=5)
    conviction: ConvictionLevel
    techno_delivery_thesis: str = Field(..., description="Assessment of delivery spikes, volume flow, and price structure")
    fundamental_thesis: str = Field(..., description="Analysis of quarterly revenue growth, margins, and concall guidance")
    catalysts: List[str] = Field(..., description="Key upcoming triggers, e.g., plant commissioning, Q2 results, order execution")
    key_risks: List[str] = Field(..., description="Specific risks to monitor, e.g., raw material inflation, promoter pledge")
    trade_setup: TradeSetup

class DailyAlphaReport(BaseModel):
    report_date: str = Field(..., description="Date of synthesis in YYYY-MM-DD format")
    market_breadth_summary: str = Field(..., description="Overall market context and sector leadership review")
    top_picks: List[ScripEvaluation] = Field(..., min_items=1, max_items=5)
    macro_notes: Optional[str]
```

## 5. Automated Cloud Execution Loop

```python
import os
import json
from google import genai
from google.genai import types

def run_eod_cloud_synthesis(top_candidates: list[str], tools_handler) -> DailyAlphaReport:
    # Initialize client (Gemini 2.5 Pro / Flash with large context window)
    client = genai.Client(api_key=os.environ["GEMINI_API_KEY"])
    
    system_prompt = open("prompts/system_prompt.txt").read()
    candidate_list_str = ", ".join(top_candidates)
    user_prompt = f"Evaluate the following Top candidate scrips for today: {candidate_list_str}. Call the necessary tools and generate the final DailyAlphaReport."
    
    # Execute tool calling loop with schema enforcement
    response = client.models.generate_content(
        model='gemini-2.5-pro',
        contents=user_prompt,
        config=types.GenerateContentConfig(
            system_instruction=system_prompt,
            temperature=0.2,
            tools=tools_handler.get_tool_declarations(),
            response_mime_type="application/json",
            response_schema=DailyAlphaReport
        )
    )
    
    return DailyAlphaReport.model_validate_json(response.text)
```
