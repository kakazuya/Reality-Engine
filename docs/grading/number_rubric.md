# Number grading rubric (T-242, from 25 Nov 2026)
Each pack row carries the printed number with its measure, printed label, period, unit, scale and basis, and the page text around it.
- R: the value is printed on the page; it is the company's own figure; measure, period, unit, scale and basis are right.
- P: the printed value is the right figure but one of measure / period / unit / scale / basis is wrong or missing, so the row reads as a different number (a segment as the total, standalone as consolidated, lakh as crore).
- W: the value is not printed on the page; or it belongs to another company, another period, another entity (customer, industry, peer), or is a calculation the page does not make.
- J: a page / note / clause / serial number, a bare year, a date, or an echo of the label's own duration ("past 3 years" -> 3) counted as a figure.
