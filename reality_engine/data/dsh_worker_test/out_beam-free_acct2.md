- **Inputs**: Reads `corpus.json` (transcript chunks of 60 random companies from `document_chunks`), `questions.json` (51 analyst questions, each paired with one target chunk), and `gold_chunks.json` (mapping each `chunk_id` to its company symbol) from `reality_engine/data/embed_test/`.
- **Providers/models**: Tests local ONNX embedding models (bge-small, bge-base, qwen3-0.6b, embeddinggemma) via `onnxruntime` on DirectML with CPU fallback; Google Gemini API models (gemini-embedding-001/2) via AI Studio `batchEmbedContents`; and OpenAI-compatible endpoints (Nebius Qwen3-8B, DeepInfra EmbeddingGemma/2, Nemotron, etc.) using API keys, with model-specific prompts/pooling.
- **What it measures**: For each model, embeds the corpus and questions, computes cosine similarity (dot product on L2-normalized vectors), ranks the gold target chunk both across the whole corpus and restricted to the asked company's chunks, reporting hit@1/5/10, MRR, chunks/s throughput (plus API calls, 429s, tokens, and cost for API models).
- **Outputs**: Caches embeddings as `emb_<model>.npy` / `qemb_<model>.npy` in `data/embed_test/`, and merges per-model metrics into `results.json` (model, provider, dim, hit rates, MRR, throughput, API stats, cost); can reuse precomputed Colab embeddings/meta files.
- **Invocation**: Run via `python -m reality_engine.scripts.embed_model_test [--models bge-small,bge-base,qwen3-0.6b,embeddinggemma]`, defaulting to those four local models.
