- **Purpose & inputs:** Embedding-model retrieval benchmark on the project's own concall data; reads `data/embed_test/{corpus.json, gold_chunks.json, questions.json}` (transcript chunks from 60 random companies, 51 analyst questions each with one target chunk), and looks up local ONNX models under `data/models/`.
- **Providers/models:** Supports local ONNX models (bge-small, bge-base, qwen3-0.6b, embeddinggemma) run via onnxruntime on DirectML with CPU fallback; Google AI Studio Gemini models (gemini-embedding-001, gemini-embedding-2); and OpenAI-compatible APIs (Nebius Qwen3-8B plus many DeepInfra models like Nemotron, Qwen, bge-m3) selected via `--models`.
- **What it measures:** For each model it embeds the corpus and questions (with model-specific instruction/prefix formatting and pooling), then computes cosine-similarity ranks in two scopes — the whole corpus (global) and only the asked company's chunks (company) — reporting hit@1/5/10, MRR, embedding dimension, throughput (chunks/s), API calls/429s, and estimated cost for API models.
- **Process:** Embeddings are cached to `data/embed_test/emb_<model>.npy` / `qemb_<model>.npy` (and can consume Colab-precomputed caches with `meta_<model>.json`), with rate limiting, batching, and key rotation for API providers; ranks are computed against the gold chunk position.
- **Outputs:** Prints per-model JSON metrics and merges results into `data/embed_test/results.json` (preserving prior models' entries), enabling comparison across runs without re-running all models.
